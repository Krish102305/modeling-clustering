# Modeling - clustering: gym member segments (who gets the monthly credit)

Code that reproduces every number in the write-up for this assignment.

- `clustering.py`: the full analysis. Run `python clustering.py` from this folder.

Requires: pandas, numpy, scikit-learn, matplotlib. Random seed fixed at 42.
